# T6.5 - Training-pair exporter

**Phase:** 6 - Evaluation and Training-Pair Flywheel
**Status:** REVIEW


**Depends on:** T6.4.
**Goal:** Export `(query, positive, hard_negatives)` pairs reproducibly.

**Spec:**
- `python -m datasets.build_training_pairs --db index/kb.sqlite3 --out datasets/training_pairs.jsonl`.
- Positive: the `clicked_project` for the query.
- Hard negatives: top-retrieved but not clicked projects, excluding the positive.
- Drop rows with `rating=-1`.
- Require at least one positive; skip queries with none.
- Output one JSON object per line:
  `{"query": "...", "positive_id": "...", "hard_negatives": ["..."], "schema_version": 1}`.
- Reproducible from `query_log` alone; sorted by `created_at, query_id`.
- Never include a senior's contact data.

**Files:**
- Create: `datasets/build_training_pairs.py`
- Test: `tests/unit/test_training_pairs.py`

**Interfaces:**
- Consumes: `query_log`.
- Produces: JSONL for Semester 2.
