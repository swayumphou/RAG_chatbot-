# T2.8 - Qdrant indexer and integrity verifier

**Phase:** 2 - Project-Aware Ingestion and Indexing
**Status:** TODO


**Depends on:** T2.7.
**Goal:** Create the collection contract and upsert chunks idempotently.

**Spec:**
- `ensure_collection(client)` creates `rupp_senior_projects_v1` only if absent, with the vectors and payload indexes from `../spec/INTERFACES.md` §4.
- `upsert_chunks(client, embedder, chunks)`:
  - encode texts in batches;
  - use `uuid5(NAMESPACE, chunk_id)` IDs;
  - `PointStruct(vector={"dense": d, "lexical": SparseVector(...)}, payload={**metadata, "text": ...})`;
  - `wait=True`;
  - return the number of points.
- `ingestion/verify.py`:
  - `count == expected_points`;
  - every point has `project_id`, `senior_ids`, `doc_id`, `doc_type`, `page_number`, `year`, `program`, `text`;
  - every `senior_ids` value exists and is active;
  - every project has at least one chunk.
- A failed assertion names the offending project.

**Files:**
- Create: `ingestion/indexer.py`, `ingestion/verify.py`
- Test: `tests/unit/test_indexer.py`

**Interfaces:**
- Consumes: `Chunk`, `Embedder`.
- Produces: `ensure_collection`, `upsert_chunks`, `assert_run_integrity`.

**Steps:**
- [ ] Implement collection creation and payload indexes.
- [ ] Implement the upsert with deterministic IDs.
- [ ] Implement the verifier.
- [ ] Add a fake-client test for the payload indexes and IDs.
- [ ] Add an integration test against a real Qdrant server for the point count.

**Acceptance:**
- [ ] Re-upserting the same chunks does not duplicate points.
- [ ] All payload indexes exist.
- [ ] `assert_run_integrity` fails on a missing key or unknown senior.
- [ ] Point IDs are stable across runs.

**Tests:** `tests/unit/test_indexer.py`

**Out of scope:** retrieval, reranking.
