# T5.7 - Sender throttle, 429, and duplicate cache

**Phase:** 5 - Telegram Interface
**Status:** TODO


**Depends on:** T5.3.
**Goal:** Survive Telegram rate limits under a demo storm.

**Spec:**
- `ChatThrottle`:
  - per-chat `asyncio.Lock`;
  - ≥ 1 s between sends to the same chat;
  - global semaphore under ~30 msg/s;
  - `RetryAfter` → sleep `retry_after`, retry once, then log and drop;
  - never blocks other chats.
- Duplicate identical query from the same chat within 30 s → cached reply, no second generation.
- Placeholder edits, if used, ≤ 1 per 2 s; prefer one final message.
- `sendChatAction("typing")` before any slow call.
- A dropped message is logged, never silent.
