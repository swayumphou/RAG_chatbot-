# T2.5 - Markdown parser

**Phase:** 2 - Project-Aware Ingestion and Indexing
**Status:** TODO


**Depends on:** T2.1.
**Goal:** Parse Markdown headings into section-anchored documents.

**Spec:**
- Use LangChain's markdown header splitter if available; otherwise a deterministic heading parser is acceptable.
- A heading starts a new section; the heading is preserved.
- `page_number=0`; anchor is `section N`.
- `doc_type="notes"` or the project's doc type.
- Empty sections are not emitted; a document with no text is `failed`.

**Files:**
- Create: `ingestion/parsers/markdown.py`
- Test: `tests/unit/test_parsers.py::test_markdown_sections_and_short_paragraph`

**Interfaces:**

- Produces: Markdown `ParsedDocument`.
