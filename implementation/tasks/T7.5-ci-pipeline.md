# T7.5 - CI pipeline

**Phase:** 7 - Deployment, Configuration, and Observability
**Status:** TODO


**Depends on:** T6.6, T7.3.
**Goal:** Automate lint, tests, and the eval regression gate.

**Spec:**
- Workflow:
  1. install dependencies;
  2. `ruff check .`;
  3. `black --check .`;
  4. `pytest tests/unit -q`;
  5. `pytest tests/integration -q` when services are configured;
  6. `python -m eval.compare_baseline eval/baseline.json eval/last_report.json`.
- Cache pip and the model directories where safe.
- Do not run the live Telegram bot in CI.
- Fail the job on any non-zero exit.
- Upload the eval report as an artifact.

**Files:**
- Create: `.github/workflows/ci.yml`
- Test: the workflow itself; run it on a branch.

**Interfaces:**
- Produces: the merge gate.

**Steps:**
- [ ] Write the workflow.
- [ ] Add the service containers for Qdrant (and Ollama if the runner can run it).
- [ ] Run it on a draft PR.
- [ ] Document the required secrets/variables.

**Acceptance:**
- [ ] A clean branch passes.
- [ ] A failing test fails the job.
- [ ] A baseline regression fails the job.
- [ ] The eval report is uploaded.

**Tests:** the workflow itself; run it on a branch.

**Out of scope:** deployment automation.
