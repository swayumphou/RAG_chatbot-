# T3.4 - Qdrant filters and facet counts

**Phase:** 3 - Five-Intent Retrieval
**Status:** TODO


**Depends on:** T3.3, T1.4.
**Goal:** Implement pre-filtering for year, program, supervisor, domain, and tech stack, plus SQLite counts.

**Spec:**
- `build_facet_filter(facets) -> models.Filter`:
  - `year` → `MatchValue(int)`;
  - `program`, `supervisor_id`, `domain` → `MatchValue(str)`;
  - `tech_stack` → `MatchAny(any=[...])`;
  - multiple facets are `must` conditions.
- Filters are passed into `hybrid_retrieve`; never post-filter in Python.
- `facet_counts(db, facets) -> dict` uses SQLite `GROUP BY` over the metadata store, not the current result page.
- Facet encoding/decoding for deep links:
  - `encode_facets({"year": 2024, "program": "DSE"}) -> "year=2024&program=DSE"` with URL-safe values;
  - `decode_facets("year=2024&program=DSE") -> dict`.
- Active filters are removable; `Clear all` is represented by an empty dict.

**Files:**
- Create: `retrieval/filters.py`
- Test: `tests/unit/test_filters.py`

**Interfaces:**
- Produces: `build_facet_filter`, `facet_counts`, `encode_facets`, `decode_facets`.
