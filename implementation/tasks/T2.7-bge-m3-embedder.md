# T2.7 - bge-m3 embedder

**Phase:** 2 - Project-Aware Ingestion and Indexing
**Status:** TODO


**Depends on:** T2.6.
**Goal:** Implement one encoder for chunks and queries that returns dense and sparse vectors.

**Spec:**
- `ingestion/embedder.py` exposes `Embedder` with `encode(texts) -> (dense, sparse_pairs)`.
- Default model `BAAI/bge-m3`, `use_fp16=True`.
- `return_dense=True`, `return_sparse=True`, `return_colbert_vecs=False`, `max_length=512`.
- Sparse pair is `(list[int], list[float])`.
- `revision` records the model name and, when available, the model commit.
- Batch large inputs (default batch size 16); never send 3,000 texts in one call.
- If the model cannot load, raise a clear error; never silently fall back to lexical-only.
- If FlagEmbedding is blocked by the environment, the fallback requires `docs/adr/ADR-002-embedding-runtime.md`; the interface stays the same.

**Files:**
- Create: `ingestion/embedder.py`
- Test: `tests/unit/test_embedder.py`

**Interfaces:**
- Produces: `Embedder` consumed by T2.8, T3.3, T4.1.
