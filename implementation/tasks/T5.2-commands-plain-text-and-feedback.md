# T5.2 - Commands, plain text, and feedback

**Phase:** 5 - Telegram Interface
**Status:** TODO


**Depends on:** T5.1.
**Goal:** Map updates to exactly one service call.

**Spec:**
- Commands: `/start`, `/help`, `/search <q>`, `/senior <name>`, `/year <yyyy>`, `/about`.
- Bare text → topic search (same path as `/search`).
- `/start senior_<id>` and `/start proj_<id>` → deep link (T5.6).
- `/senior` with no args → help for that command.
- 👍/👎 callback → `db.rate(query_id, value)`; non-blocking; the rating button disappears after use.
- No retrieval, ranking, threshold, or prompt logic in handlers.
- Send one `answer()` call per interaction.

**Files:**
- Create: `bot/handlers.py`
- Test: `tests/unit/test_bot.py::test_commands_and_plain_text_call_one_service`

**Interfaces:**
- Consumes: `answer.service.answer`.
- Produces: handler functions registered in T5.1.
