# T4.5 - Citation validator and fallback

**Phase:** 4 - Extractive-First Answer Layer
**Status:** TODO


**Depends on:** T4.4.
**Goal:** Deterministically reject invented projects or pages and serve the extractive answer.

**Spec:**
- Regex: `\[Project:\s*(.+?),\s*p\.(\d+)\]`.
- Allowed set: `{(citation.title, str(citation.page_number))}`.
- Valid when at least one citation is found and every found pair is in the allowed set.
- No citations → invalid.
- Invalid → `mode="extractive_fallback"`, log the event, serve extractive citations.
- A model never validates another model's citations.

**Files:**
- Create: `answer/validate.py`
- Modify: `answer/service.py`
- Test: `tests/unit/test_validate.py`

**Interfaces:**
- Produces: `validate_citations(text, citations) -> bool`.

**Steps:**
- [ ] Implement the regex and allowed-set check.
- [ ] Add tests for no citation, valid citation, wrong page, wrong title, and a citation to a non-retrieved project.
- [ ] Add a service test that a bad citation returns `extractive_fallback`.

**Acceptance:**
- [ ] `[Project: X, p.4]` passes only when `("X", "4")` is retrieved.
- [ ] An invented title or page fails.
- [ ] Failure falls back and logs.

**Tests:** `tests/unit/test_validate.py`

**Out of scope:** semantic faithfulness judging.
