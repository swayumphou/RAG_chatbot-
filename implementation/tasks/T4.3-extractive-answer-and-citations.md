# T4.3 - Extractive answer and citations

**Phase:** 4 - Extractive-First Answer Layer
**Status:** TODO


**Depends on:** T4.2.
**Goal:** Produce a useful default answer from the retrieved passages with project/page citations.

**Spec:**
- For each of the top 5 grouped projects:
  - use the best chunk verbatim (snippet capped at 400 chars in cards, full text in the answer if needed);
  - citation: `project_id`, `title`, `senior_ids`, `page_number`, `snippet`, `matched_by`, `score`.
- `AnswerResult.mode="extractive"`, `answer=None`; the renderer (bot/CLI) composes the text from `citations`.
- Do not paraphrase and do not call the LLM.
- Deduplicate citations by `(project_id, page_number)`.
- Keep the fused order after grouping.
