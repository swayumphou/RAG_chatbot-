# T5.4 - Portfolio rendering and pagination

**Phase:** 5 - Telegram Interface
**Status:** TODO


**Depends on:** T3.6, T5.3.
**Goal:** Render a portfolio from SQLite with newest-first projects and pagination.

**Spec:**
- `portfolio_card(portfolio) -> str`:
  - name (Latin + Khmer), program, cohort, supervisor;
  - `Projects (N)` newest first;
  - each project: title, year, role if present;
  - `Connect:` block only from `contact_card` (T4.6);
  - metadata-only label when `metadata_only=True`.
- A portfolio longer than 4096 chars is paginated with `paginate()`; never truncated.
- The `Portfolio` button opens the first author's portfolio; multiple authors use a candidate list.
- Pagination callback `pg:<project_id>:<page>` is for result pages; portfolio pagination uses `pf:<senior_id>:<page>`.
- No Qdrant call.

**Files:**
- Modify: `bot/format.py`, `bot/handlers.py`
- Test: `tests/unit/test_format.py::test_portfolio_paginates_and_labels_metadata_only`

**Interfaces:**
- Produces: `portfolio_card`.
- Consumes: `Portfolio`.
