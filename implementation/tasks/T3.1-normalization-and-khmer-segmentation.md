# T3.1 - Normalization and Khmer segmentation

**Phase:** 3 - Five-Intent Retrieval
**Status:** TODO


**Depends on:** T1.4.
**Goal:** One normalization path for names and queries, plus Khmer lexical segmentation.

**Spec:**
- `normalize(text)`:
  - Unicode NFKC;
  - casefold;
  - strip Latin diacritics only when the text contains no Khmer;
  - collapse whitespace;
  - remove punctuation that is not Khmer (`។`, `៕`, `៖` are punctuation and may be normalized).
- `contains_khmer(text)` checks `\u1780`–`\u17ff`.
- `segment_for_lexical(text)`:
  - non-Khmer → returned unchanged;
  - Khmer → `khmernltk.word_tokenize`, joined with spaces;
  - if `khmernltk` is unavailable, fall back to character trigrams **only** with a warning, never silently.
- The same `normalize()` is used for `senior.name_normalized`, `senior_alias.alias_normalized`, and query routing.

**Files:**
- Create: `retrieval/intent.py` (normalization block)
- Test: `tests/unit/test_intent.py::test_normalize_keeps_khmer_and_strips_latin`

**Interfaces:**
- Produces: `normalize`, `contains_khmer`, `segment_for_lexical`.
