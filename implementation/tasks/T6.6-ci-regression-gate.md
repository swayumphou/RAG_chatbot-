# T6.6 - CI regression gate

**Phase:** 6 - Evaluation and Training-Pair Flywheel
**Status:** TODO


**Depends on:** T6.3, T6.5.
**Goal:** Fail a change that breaks retrieval quality.

**Spec:**
- `eval/compare_baseline.py baseline.json last_report.json`:
  - fail if any slice's nDCG@10 drops > 0.02;
  - fail if a required slice is missing;
  - fail if the golden-set hash differs;
  - fail if the loaded model tag differs from the baseline.
- Exit `0` on pass, `1` on failure.
- CI runs unit tests, then the eval comparison (with services available).
- The baseline is committed and never regenerated silently.

**Files:**
- Create: `eval/compare_baseline.py`
- Test: `tests/unit/test_metrics.py::test_compare_baseline_gate`

**Interfaces:**
- Consumes: `baseline.json`, `last_report.json`.
- Produces: CI exit code.

**Steps:**
- [ ] Implement the comparison.
- [ ] Add tests for pass, nDCG drop, missing slice, hash mismatch, and tag mismatch.
- [ ] Document the CI command in `../spec/TESTING.md` §8.

**Acceptance:**
- [ ] A clean report passes.
- [ ] A 0.03 nDCG drop fails.
- [ ] A missing slice fails.
- [ ] A different model tag fails.

**Tests:** `tests/unit/test_metrics.py::test_compare_baseline_gate`

**Out of scope:** deploying the bot.
