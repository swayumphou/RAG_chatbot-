# T4.4 - Gemma 4 synthesis

**Phase:** 4 - Extractive-First Answer Layer
**Status:** TODO


**Depends on:** T4.1.
**Goal:** Optional LLM mode that answers only from the top-5 grouped projects.

**Spec:**
- `answer/prompts.py` calls Ollama `/api/chat`.
- Model `gemma4:12b-it-qat` by default; tag pinned and logged.
- Options: `temperature=0.0`, `num_ctx=8192`, `num_predict=600`.
- System prompt:
  - use only the passages inside `<retrieved_projects>`;
  - cite every factual sentence as `[Project: <title>, p.<page>]`;
  - if the passages do not answer, output exactly `LLM_NO_ANSWER`;
  - never invent a senior, supervisor, year, or repository link;
  - keep the answer under 900 characters.
- User message contains only the top-5 grouped projects and the query.
- Contact fields are never included.
- On timeout, connection error, or `done_reason="length"`, raise a typed error that the service converts to extractive fallback.
- Log the model tag and latency.

**Files:**

- Modify: `answer/service.py`
