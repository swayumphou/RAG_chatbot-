# T2.3 - DOCX parser

**Phase:** 2 - Project-Aware Ingestion and Indexing
**Status:** TODO


**Depends on:** T2.1.
**Goal:** Parse DOCX headings and tables into section-anchored documents.

**Spec:**
- Use `python-docx`.
- Iterate blocks in document order (`iter_inner_content`).
- A heading/title starts a new section; the section text includes the heading and following paragraphs.
- Tables are rendered row by row as `cell | cell | cell`.
- Page number is `0` (DOCX has no reliable pages); anchor is `section N`.
- Empty sections are not emitted.
- If no text is produced, return `failed`.

**Files:**
- Create: `ingestion/parsers/docx.py`
- Test: `tests/unit/test_parsers.py::test_docx_headings_tables_and_anchor`

**Interfaces:**
- Consumes: T2.1 contract.
- Produces: DOCX `ParsedDocument` with `doc_type="report"` unless the project says otherwise.

- [ ] Assert a heading-only document does not emit empty text.

**Acceptance:**
