# T2.2 - PDF parser and OCR fallback

**Phase:** 2 - Project-Aware Ingestion and Indexing
**Status:** REVIEW
**Note:** Tesseract is not installed on the dev machine, so OCR output is unverified; the scanned fixture is reported as `failed` (never a silent `ok`).


**Depends on:** T2.1.
**Goal:** Parse born-digital PDFs page by page and OCR scanned pages.

**Spec:**
- Use PyMuPDF (`fitz`/`pymupdf`); do not silently use a different PDF library.
- For each page:
  - extract text blocks (`get_text("blocks")`, text blocks only);
  - detect headings from font sizes noticeably larger than the body size;
  - if the page text has < 20 non-whitespace characters, render at 300 dpi and run Tesseract `eng+khm`;
  - if OCR is used, set the document `parse_status="ocr"`;
  - if a page yields no text after extraction/OCR, skip it but keep the page count.
- If no pages yield text, return `parse_status="failed"` with `pages=()`.
- `page_count` is the original PDF page count.
- Do not raise on a failed OCR library import; return empty text for that page and let the document become `failed` if all pages are empty.

**Files:**
- Create: `ingestion/parsers/pdf.py`, `ingestion/parsers/ocr.py`
- Test: `tests/unit/test_parsers.py::test_pdf_pages_and_ocr_flag`

**Interfaces:**

- Produces: PDF `ParsedDocument`.
