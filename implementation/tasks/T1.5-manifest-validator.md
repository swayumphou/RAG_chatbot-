# T1.5 - Manifest validator

**Phase:** 1 - Data Model and Manifest
**Status:** REVIEW
**Note:** Empty corpus folder is a warning (metadata-only), missing folder is an error: [ADR-004](../../docs/adr/ADR-004-metadata-only-projects.md) (Proposed).


**Depends on:** T1.4.
**Goal:** Implement `validate_manifest` exactly as specified, failing before any Qdrant write.

**Spec:**
- `REQUIRED_PROJECT = ["project_id","title_en","year","program","supervisor_id","senior_ids","abstract","permission"]`.
- `REQUIRED_SENIOR = ["senior_id","full_name_latin","program","cohort_year"]`.
- Errors:
  - missing required field;
  - duplicate `project_id`;
  - duplicate `senior_id`;
  - unknown `senior_id` in `senior_ids`;
  - missing corpus folder for a granted project;
  - `permission=granted` project with no files in its folder.
- Warnings:
  - `permission != "granted"` → skip;
  - `status=withdrawn` → skip;
  - a file in the corpus folder with no manifest row → orphan warning.
- `corpus_hash(corpus_dir)` is order-independent over relative path + file SHA-256.
- `ValidationReport.ok` is true only when `errors` is empty.
- `validate_manifest` performs no Qdrant or network calls.

**Files:**
- Create: `ingestion/validate_manifest.py`
- Modify: `store/db.py` only if a read helper is missing
- Test: `tests/unit/test_manifest.py`

**Interfaces:**
- Consumes: `corpus_hash`, CSV rows.
- Produces: `ValidationReport` (see `../spec/INTERFACES.md` §5.1).

**Steps:**
- [x] Implement `corpus_hash`.
- [x] Implement required-field and duplicate checks.
- [x] Implement referential and permission checks.
- [x] Implement the corpus-folder and orphan-file checks.
- [x] Write one test per rejection fixture from `../spec/TESTING.md` §2.1.

**Acceptance:**
- [x] The valid fixture returns `ok=True`.
- [x] Every invalid fixture returns a per-row error naming the line.
- [x] A pending project is a warning and is absent from `report.projects`.
- [x] A withdrawn senior is a warning and their project is skipped.
- [x] The report contains a stable `corpus_hash`.

**Tests:** `tests/unit/test_manifest.py`

**Out of scope:** parsing, chunking, embedding.
