# T5.3 - Formatter and project cards

**Phase:** 5 - Telegram Interface
**Status:** TODO


**Depends on:** T5.2.
**Goal:** Render safe, compact project cards with the exact buttons.

**Spec:**
- `esc(text) = html.escape(text, quote=False)`; escape before adding tags.
- `project_card(citation, page, total)`:
  - `<b>{title}</b>`;
  - authors, year, program, supervisor;
  - verbatim snippet (≤ 400 chars);
  - `— {title}, p.{page}`;
  - `matched: semantic + keyword` (or the actual path);
  - buttons: `Abstract`, `Portfolio`, `Repo` (only if a URL exists), `Next ▶` (only if `page < total - 1`).
- Callback data: `ab:<project_id>`, `pf:<senior_id>`, `pg:<project_id>:<page>`; each ≤ 64 bytes.
- `paginate(text, 4096)` splits on blank lines; never truncates a paragraph silently (a pathological single paragraph is split at the limit with a continuation marker).
- `parse_mode=HTML`; `disable_web_page_preview=True`.

**Files:**
- Create: `bot/format.py`
- Test: `tests/unit/test_format.py`

**Interfaces:**
- Produces: `paginate`, `project_card`.
- Consumes: `Citation`.

**Steps:**
- [ ] Implement escaping and the card.
- [ ] Implement pagination with the pathological-paragraph rule.
- [ ] Add tests for HTML injection in a title, the 4096 limit, button payload size, and `Next` visibility.
- [ ] Add a test that a missing repo URL omits the button.

**Acceptance:**
- [ ] `<script>` in a title is escaped.
- [ ] Every message is ≤ 4096 chars.
- [ ] Callback data is ≤ 64 bytes.
- [ ] Buttons appear only when their data exists.

**Tests:** `tests/unit/test_format.py`

**Out of scope:** sending messages (T5.7).
