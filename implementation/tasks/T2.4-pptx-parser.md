**Goal:** Parse slides, speaker notes, and tables into one document per slide.

**Spec:**
- Use `python-pptx`.
- One `Page` per slide; `number` is the slide number.
- Include text frames, table cells, and speaker notes.
- If a title exists, use it as the heading; otherwise use the first non-empty line.
- `doc_type="slides"`; later chunking uses the 300/50 splitter.
- A slide with no text is skipped; if all slides are empty, `failed`.
