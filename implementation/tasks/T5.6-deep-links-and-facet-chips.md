# T5.6 - Deep links and facet chips

**Phase:** 5 - Telegram Interface
**Status:** TODO


**Depends on:** T3.4, T5.2.
**Goal:** Make portfolios, projects, and facet views shareable.

**Spec:**
- `?start=senior_<senior_id>` → portfolio directly.
- `?start=proj_<project_id>` → project abstract/card directly.
- Invalid/unknown ID → explicit not-found reply, no crash.
- Facet browse `/year 2024`:
  - text: `2024 · N projects`;
  - chips: `DSE 8`, `ITE 4`, `Clear all`;
  - filters encoded in the deep link (`year=2024&program=DSE`);
  - active filters are removable.
- Result count must equal the SQLite `GROUP BY` count; a mismatch is a test failure.
- Callback data for chips stays ≤ 64 bytes.

**Files:**
- Modify: `bot/handlers.py`, `bot/format.py`
- Test: `tests/unit/test_bot.py::test_deep_links_and_facet_chips`

**Interfaces:**
- Consumes: `encode_facets`, `decode_facets`, `facet_counts`.
- Produces: deep-link and facet handlers.

**Steps:**
- [ ] Parse the `start` payload.
- [ ] Implement portfolio and project deep links.
- [ ] Implement facet rendering and chips.
- [ ] Add tests for both deep links and an invalid ID.
- [ ] Add a test that the result count equals the SQLite count.

**Acceptance:**
- [ ] `senior_<id>` opens the portfolio.
- [ ] `proj_<id>` opens the project.
- [ ] Facet chips encode and clear filters.
- [ ] Invalid IDs fail gracefully.

**Tests:** `tests/unit/test_bot.py::test_deep_links_and_facet_chips`

**Out of scope:** group chats.
