# T5.1 - Bot bootstrap and private-chat envelope

**Phase:** 5 - Telegram Interface
**Status:** TODO


**Depends on:** T4.7.
**Goal:** Start the bot with one service instance and a safe update envelope.

**Spec:**
- `python -m bot.main` long polling; `--check` runs readiness without contacting Telegram.
- Token from `TELEGRAM_BOT_TOKEN` only; prompt only in interactive local mode; never log it.
- Private chats only in Semester 1; ignore edited messages.
- `send_chat_action("typing")` immediately for every text/callback that will answer.
- Register handlers: commands, plain text, callback prefixes, error handler.
- A handler exception returns a short capability hint; the polling loop never dies.
- `bot_data` holds the shared `answer` service dependencies (client, embedder, db, threshold, enable_llm).
- Log startup with the loaded model tags.

**Files:**
- Create: `bot/main.py`
- Test: `tests/unit/test_bot.py::test_bootstrap_private_only_and_no_token_logging`

**Interfaces:**
- Consumes: `answer.service.answer`.
- Produces: the application object used by handler tests.

**Acceptance:**
