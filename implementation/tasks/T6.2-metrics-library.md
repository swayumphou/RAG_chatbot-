# T6.2 - Metrics library

**Phase:** 6 - Evaluation and Training-Pair Flywheel
**Status:** REVIEW


**Depends on:** T6.1.
**Goal:** Implement the five required metrics plus payload integrity.

**Spec:**
- `recall_at_k(rows, k=5)`: fraction of queries with at least one expected project in the top k.
- `mrr_at_k(rows, k=10)`: mean reciprocal rank of the first expected project, 0 if none.
- `ndcg_at_k(rows, k=10)`: graded relevance using binary gains (one expected project = 1), `DCG = Σ rel_i / log2(i+1)`, `IDCG` from the ideal ordering.
- `name_top1(rows)`: fraction of name queries whose first resolved senior equals `expected_senior_id`.
- `abstention_precision(rows)`: fraction of negatives that abstain.
- `payload_integrity(rows)`: fraction of retrieved projects with all required payload keys.
- Each function accepts a list of plain dicts, so it is testable without Qdrant.
- Return `None` for an empty slice, not a division-by-zero.

**Files:**
- Create: `eval/metrics.py`
- Test: `tests/unit/test_metrics.py`

**Interfaces:**
- Produces: the metric functions consumed by T6.3 and T6.6.
