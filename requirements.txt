# Exact, tested versions. Install with:
#
#     .venv\Scripts\python.exe -m pip install --no-deps -r requirements.txt
#
# --no-deps is required. Why exact pins and --no-deps:
#   * Tested on Windows 11 with Smart App Control ON and Python 3.15. Smart App Control judges every
#     compiled file separately, so each compiled package below is a build verified to load there.
#     grpcio, xxhash and uuid-utils are deliberately NOT the newest release - the newest are blocked.
#   * PyYAML and zstandard are left out on purpose: they have no Python 3.15 wheels and cannot be
#     built on this machine. LangChain only uses them for YAML prompt files and LangSmith trace
#     uploads, which this project never touches. Without --no-deps pip tries to build them and fails.
#   * Embeddings and the LLM run in Ollama, so PyTorch is not needed at all.
